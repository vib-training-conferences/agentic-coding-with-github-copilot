
# What do you need to follow the course:

Acounts and Licenses
---------------------

To complete the course, you need to have a GitHub Copilot [Pro]((https://github.com/features/copilot/plans)) or [Education License](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-teachers-and-os-maintainers).

Device requirement
--------------------

* Bring your own computer
